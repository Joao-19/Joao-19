## ToolKit Pessoal

Ferramenta de uso pessoal e não comercial, desenvolvida por João Vitor para acessar os próprios arquivos entre o celular, os computadores e o Google Drive do próprio desenvolvedor. Inclui o app Android ToolKit e as ferramentas de sincronização (rclone) dos computadores pessoais.

// política de privacidade

## Política de Privacidade

Última atualização: 23 de outubro de 2026.

Quem usa. O ToolKit Pessoal é usado exclusivamente pelo próprio desenvolvedor, com a própria conta Google. Não é distribuído nem oferecido a terceiros.

Dados acessados. Com a autorização do usuário (OAuth do Google), o app acessa os arquivos do Google Drive da conta conectada, apenas para listar, baixar, enviar, renomear e excluir arquivos a pedido do próprio usuário.

Uso e armazenamento. Os dados trafegam somente entre o Google Drive e os dispositivos do próprio usuário (celular e computadores pessoais). Não existe servidor intermediário, não há coleta, análise, publicidade, venda ou compartilhamento de dados com terceiros. Os tokens de acesso ficam guardados apenas no armazenamento seguro de cada dispositivo.

Uso dos dados do Google. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar acesso. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
